---
name: summarize-and-share
description: Summarize one note and share that summary after the person picks a destination and confirms. Use when someone wants a short version of a note sent onward.
---

This skill is guidance for a series of tools. ShareSummary is the only tool that sends anything, and only after confirmation.

1. If no note is chosen, ask which note and stop.
2. Shorten the note to a single paragraph. Do not add facts that are not in the note.
3. If no destination was named, ask them to choose Messages, Mail, or Copy.
4. Show the summary and the destination, and ask before sharing.
5. If they decline, call nothing and say that nothing was shared.
6. If they confirm, call ShareSummary with the note, the destination, and the summary.
