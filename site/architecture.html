Why the split

A skill file does not execute. The assistant reads it and calls tools. The package still models the questions those tools have to ask — a missing value, a choice, a confirmation — so you can test the path on Linux before a simulator exists. The same inputs drive the sample’s studio.

Indexing follows the same idea. The coordinator is pure. The bridge is the only type that touches CSSearchableIndex. Inserts and updates both go through indexAppEntities, because that call replaces an identifier that is already there. Deletes use deleteAppEntities(identifiedBy:ofType:).
