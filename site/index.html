Teach a multi-step skill without inventing the plumbing.

Skillstrand is a Swift package for iOS apps that need tool intents, entities, Spotlight indexing, and a short guidance file the system assistant can follow. It is built for Siri AI’s developer preview, and it keeps that name out of the product mark.

What you drop into an app

Tool intents

A parameter builder, dialog copy, and an error map. On device those become AppIntent results, confirmation, and disambiguation.

Entities

Property conventions plus an in-memory stand-in for EntityQuery and EntityStringQuery. The sample adopts IndexedEntity.

Spotlight

A sync coordinator that diffs fingerprints into insert, update, and delete batches, then a bridge onto a named CSSearchableIndex.

Four skills, each with a follow-up

Capture to task

Read a title, confirm before saving, then ask whether to add a due date.

Search and open

A string query that opens one hit and asks when “field” matches two items.

Summarize and share

Shorten a note, pick Messages, Mail, or Copy, and confirm before anything leaves.

Scheduled reminder

“Friday” is two times. The person picks one, then confirms the reminder.
