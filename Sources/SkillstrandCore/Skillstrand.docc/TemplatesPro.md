# Template pack

The paid template pack is sold separately and is not part of this MIT-licensed package.

## Overview

The pack adds `booking-hold`, `inbox-triage`, and `album-share`, plus Xcode file templates for a tool intent, an indexed entity, and a skill file. It also includes a `GenerableDraft.swift` reference that shows the documented `GenerableEntity` annotation and is not compiled.

Launch price is $49 until 14 December 2026, then $79, one-time. Checkout is not connected yet. This repository does not include a payment SDK, a store product, or a checkout URL.
